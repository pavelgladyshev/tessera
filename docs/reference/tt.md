# Package tt

```go
import "github.com/pavelgladyshev/tessera/tt"
```

This page is made from the package's doc comments by `tools/apidoc`.
{: .fs-2 }

Package tt is the Tessera runtime.

A Tessera program is a Go program that uses this package. Run it with
`go run` and this package executes it on the CPU; compile it with tessc and
the same program runs on a Tenstorrent Wormhole card. The CPU version is the
reference: the card must produce the same results, up to bf16 rounding and
the accuracy of its math approximations.

## Functions

### Abs

```go
func Abs(x float32) float32
```

Abs returns |x|.

### CloseCard

```go
func CloseCard()
```

CloseCard releases the card. Code generated by tessc calls it when main
returns.

### Cores

```go
func Cores() int
```

Cores is the number of Tensix cores the card has for workers, one per
worker: tt.Parallel(tt.Cores(), ...) uses them all. An n300 has 128 (64
on each of its two chips). Run on the CPU, without a card, Cores is 128
too, or what the environment variable TESSERA_CORES says, so that the
CPU splits the work as the card would.

### Cos

```go
func Cos(x float32) float32
```

Cos returns the cosine of x (radians).

### Exp

```go
func Exp(x float32) float32
```

Exp returns e**x.

### Launch

```go
func Launch[T any](k Kernel, n int, work func(w int, out *List[T]), args []CardArg) []T
```

Launch is Parallel for a program compiled by tessc: tessc rewrites each
tt.Parallel(n, work) into tt.Launch(kernel, n, work, args), where kernel is
work compiled for the card and args are the variables of main that work
uses. With a card in use the workers run there; otherwise Launch is
Parallel.

T is a struct of integers and bools (tessc checks this), laid out on the
card exactly as in Go, so a record is copied as it is.

### Linear

```go
func Linear(y, x Tensor, l Layer)
```

Linear sets y to x·W + b, row by row, on the core's matrix engine. x and
y must be different tensors with the same number of rows.

### LinearCat

```go
func LinearCat(y Tensor, l Layer, xs ...Tensor)
```

LinearCat is Linear on the tensors xs side by side: row r of the input is
row r of each of them, one after another (up to 7). Nothing is copied: the
matrix engine adds up the products. On the card every tensor but the last
must have a multiple of 32 columns.

### LinearReLU

```go
func LinearReLU(y, x Tensor, l Layer)
```

LinearReLU is Linear followed by max(0, ·).

### LinearReLUCat

```go
func LinearReLUCat(y Tensor, l Layer, xs ...Tensor)
```

LinearReLUCat is LinearCat followed by max(0, ·).

### Parallel

```go
func Parallel[T any](n int, work func(w int, out *List[T])) []T
```

Parallel runs work(w, out) for w = 0, 1, ..., n-1 at the same time and
waits for all of them. Each worker appends its results to its own list;
Parallel returns them all, worker 0's first, each worker's in the order it
appended them.

On the CPU every worker is a goroutine. On the card every worker runs on a
Tensix core of its own.


### WriteFile

```go
func WriteFile(path string, b Bytes, off, n int)
```

WriteFile writes the n bytes of b that start at offset off to a new file,
creating its directory if needed. The range is cut at the end of b.
Several goroutines can call it at once.

From a file, the bytes go from b's file to the new one without passing
through the program (Linux copies them with copy_file_range), so writing
carved files from a disk image costs little more than the disk's writes.

## Types

### type Array

```go

	// contains filtered or unexported fields
}
```

Array is a two-dimensional array of numbers that lives on the card.

On the card the values are bf16. On the CPU they are float32 values; Load
rounds them to bf16 so that both sides start from the same inputs.

### type Bytes

```go
type Bytes struct {
	// contains filtered or unexported fields
}
```

Bytes is a read-only array of bytes, such as a disk image, that workers
read pieces of with Read.

LoadBytes reads the whole file up front; on the card it is then copied to
DRAM. OpenBytes reads only what the workers ask for: on the card each
worker asks the host for the blocks it needs, so a program that reads a
file sparsely (a carver that probes one block in a hundred, say) reads
only those blocks from the disk.

#### LoadBytes

```go
func LoadBytes(path string) Bytes
```

LoadBytes reads a whole file.

#### OpenBytes

```go
func OpenBytes(path string) Bytes
```

OpenBytes opens a file to be read on demand.

#### (Bytes) BytesRead

```go
func (b Bytes) BytesRead() int
```

BytesRead returns how many bytes have been read from the file so far. For
LoadBytes that is the whole file. It is for main.

#### (Bytes) Len

```go
func (b Bytes) Len() int
```

Len returns the number of bytes.

#### (Bytes) Read

```go
func (b Bytes) Read(buf []byte, off int) int
```

Read copies bytes starting at offset off into buf and returns how many it
copied: len(buf), or fewer at the end of b. A read that starts at or past
the end copies nothing and leaves buf as it was.

#### (Bytes) ReadStrided

```go
func (b Bytes) ReadStrided(buf []byte, off, stride, size int) int
```

ReadStrided reads evenly spaced pieces of b: piece i is the size bytes at
offset off+i*stride, copied into buf[i*size:(i+1)*size]. len(buf) must be a
whole number of pieces. Each piece is read as Read would read it (fewer
bytes at the end of b, none past it), and ReadStrided returns how many
bytes it copied in all.

On the card, a worker reading from OpenBytes asks the host for all the
pieces at once (up to 128 KiB of them), so it waits for one round trip to
the host instead of one per piece.

### type Card

```go
type Card interface {
	LoadBytes(path string) int	// copies the file to the card; returns a handle
	OpenBytes(path string) int	// lets the card's workers read the file on demand
	LoadDetector(path string) int	// puts the detector's weights on the card
	BytesRead(handle int) int	// bytes of an OpenBytes file the card's workers have read
	// PutLayer and PutMatrix put a tt.Layer's weights and a tt.Matrix's
	// values on the card.
	PutLayer(in, out int, w, b []float32) int
	PutMatrix(rows, cols int, v []float32) int
	Cores() int	// Tensix cores for workers, on all the card's chips
	// Launch runs the kernel on n workers and returns their records,
	// recordBytes each, worker 0's first.
	Launch(k Kernel, n, recordBytes int, args []CardArg) []byte
	Close()	// releases the card
}
```

Card is how a program that tessc compiled for the card reaches it. Such a
program runs main as ordinary Go on the host. Code that tessc generates
installs a Card with UseCard (package tt/card provides one, which talks to
a helper process that owns the card), and from then on LoadBytes,
OpenBytes and LoadDetector also put their data on the card, and Launch
runs workers there. Programs do not use Card themselves.

### type Detector

```go
type Detector struct {
	// contains filtered or unexported fields
}
```

Detector is ndeca's block classifier: the PatchMLP network that labels a
disk block as the header, a body (middle) block or the footer of one of
several file types, or as other. Load it in main with LoadDetector; use
Label there to find a class, and Classify in worker code.

On the CPU it runs in float32, exactly as ndeca's model.py. On the card it
runs on the matrix engine of the worker's own Tensix core, in bf16 with
float32 accumulation, so a block close to a tie between two classes can
come out differently.

#### LoadDetector

```go
func LoadDetector(path string) Detector
```

LoadDetector reads a network exported with tools/export_ndeca.py.

#### (Detector) BlockSize

```go
func (d Detector) BlockSize() int
```

BlockSize returns the number of bytes the detector classifies at a time.

#### (Detector) ClassName

```go
func (d Detector) ClassName(i int) string
```

ClassName returns the name of class i, such as "jpeg.body". It is for main.

#### (Detector) Classify

```go
func (d Detector) Classify(block []byte) int
```

Classify returns the label of block, which must be BlockSize bytes long:
the class with the largest logit.

#### (Detector) ClassifyBatch

```go
func (d Detector) ClassifyBatch(blocks []byte, labels []int)
```

ClassifyBatch labels len(labels) blocks at once: blocks holds them one
after another, BlockSize bytes each. On the card a batch shares one pass
of the network's largest layer, so it is much faster per block than
calling Classify for each.

#### (Detector) Label

```go
func (d Detector) Label(name string) int
```

Label returns the index of the class with the given name, such as
"jpeg.body". It is for main; pass the index to the workers.

#### (Detector) Logits

```go
func (d Detector) Logits(block []byte) []float32
```

Logits returns the network's output for block. It is not available in
worker code on the card; it is here for checking.

### type Kernel

```go
type Kernel struct {
	Name		string		// its source file in the program's kernel directory
	Scratch		int		// bytes of L1 scratch each worker needs for its arrays
	Capacity	int		// how many results one worker can append
	Positions	[]Position	// the places in the Go source where a worker can fail

```

Kernel describes the worker kernel that tessc compiled from the function
given to Parallel.

### type Layer

```go
type Layer struct {
	// contains filtered or unexported fields
}
```

Layer is a linear layer: y = x·W + b, for x of in columns and y of out.
Make it in main with NewLayer and use it in worker code with Linear and
LinearReLU.

#### LayerOf

```go
func LayerOf(w, b NNTensor) Layer
```

LayerOf makes a layer from tensors that main computed with package
tt/nn: w is in × out (w[i][j] for input i and output j) and b has out
elements, or is nil for no biases. On the card nothing is copied: the
workers read ttnn's tensors, as they are when the workers start. The
layer keeps them, so w and b can be freed.

#### NewLayer

```go
func NewLayer(in, out int, w, b []float32) Layer
```

NewLayer makes a layer from its weights, w[i*out+j] for input i and output
j, and its biases b (nil for none).

### type Matrix

```go
type Matrix struct {
	// contains filtered or unexported fields

```

Matrix is a table of values that worker code copies rows from (an
embedding table, say). Make it in main with NewMatrix.

#### MatrixOf

```go
func MatrixOf(t NNTensor) Matrix
```

MatrixOf makes a matrix, for worker code to copy rows from, of a rows ×
cols tensor that main computed with package tt/nn. The matrix is a copy
of the tensor as it is now (made on the card, not through the host).

#### NewMatrix

```go
func NewMatrix(rows, cols int, v []float32) Matrix
```

NewMatrix makes a rows × cols matrix of values, v[r*cols+c].

### type NNCard

```go
type NNCard interface {
	NN(req []byte) ([]byte, error)
}
```

NNCard is a Card that can also run package tt/nn's requests, through
ttnn. A request and its answer are nn's own business; an error is what
ttnn said, and leaves the card usable.

### type NNTensor

```go

```

NNTensor is a tensor of package tt/nn (an nn.Tensor), as LayerOf and
MatrixOf see it: its shape, and its numbers (on the CPU) or its handle on
the card.

### type Tensor

```go
type Tensor struct {
	// contains filtered or unexported fields
}
```

Tensor is a rows × cols matrix of numbers on the worker's core. Make one
in worker code with NewTensor.

#### NewTensor

```go
func NewTensor(rows, cols int) Tensor
```

NewTensor returns a rows × cols tensor of zeros. On the card rows and
cols must be constants, and each NewTensor in the program has one place
in the core's memory: calling it again gives that tensor back, zeroed. A
program can have 26.

#### (Tensor) ArgMax

```go
func (t Tensor) ArgMax(r int) int
```

ArgMax returns the column of the largest element of row r (the first, if
several are equal).

#### (Tensor) CopyRow

```go
func (t Tensor) CopyRow(r, c int, m Matrix, i int)
```

CopyRow copies row i of m into row r of t, starting at column c.

#### (Tensor) CopyRowOf

```go
func (t Tensor) CopyRowOf(r, c int, s Tensor, i int)
```

CopyRowOf copies row i of the tensor s into row r of t, starting at
column c.

#### (Tensor) Rows

```go
func (t Tensor) Rows(first, n int) Tensor
```

Rows returns rows first to first+n-1 of t as a tensor that shares t's
numbers: an operation on it reads or writes that part of t. On the card
first must be a multiple of 32, and n too unless the rows go to t's end.

#### (Tensor) Scaled

```go
func (t Tensor) Scaled(r, c, scale int) int
```

Scaled returns element (r, c) times scale, rounded to the nearest
integer: the way to read a number without floating point.

#### (Tensor) Set

```go
func (t Tensor) Set(r, c, num, den int)
```

Set sets element (r, c) to num/den.

#### (Tensor) Zero

```go
func (t Tensor) Zero()
```

Zero sets every element to 0.
